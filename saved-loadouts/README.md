# Saved loadouts

Tycoon Sim 2 loadouts are standalone `*.tycoon-loadout.json` files.

- Use **Save Base** in the planner and choose this folder when the browser asks where to save the file.
- Share a loadout by sending its JSON file.
- To add someone else's base, copy its file here, then use **Load Bases → Import saved-loadouts folder** in the planner.
- The planner validates a loadout against the current item database before replacing the grid.

The browser also keeps an indexed copy of imported and saved loadouts locally so the Load Bases menu can open quickly.
